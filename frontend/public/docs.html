系统架构

三层解耦：引擎（Python）、Redis 总线、前端（Node + 浏览器）。任意一层可独立重启，共享状态仅在 Redis。

引擎内模块（python main.py）

模块职责
strategy.pyIBKR K 线、SuperTrend/EMA/VWAP → Redis
signal_detector.pyM1 触线 → st_super 信号 → 提案池
reclaim_watcher.py条件单：approved_wait → ready_to_execute
auto_runner.pyAlpha → RiskGate → AutoPM 编排；消费 auto:close
execution/auto_pm.py仓位单元、OCA 止损/止盈、对账、IBKR 报单
order_actor.pyHTTP :8888 网关（平仓/trail；开仓已禁）
exit_manager.py手动 trail 止盈、非 auto 标的 EOD 15:45

实盘开仓唯一路径

触线 / MCP 扫信号→ pending 提案→ 审批 approved_live→ AutoRunner→ RiskGate 定量→ AutoPM → IBKR

手动 Bracket / HTTP /order 已禁止（403）。FA 分配由 IB_FA_GROUP / IB_FA_METHOD 在引擎注入，上层不传 account。

平仓两条路径

AutoPM 接管auto_strategy 或 opening_breakout_live → UI DELETE /api/position → Redis auto:close:{sym} → AutoPM close_all
手动 / trail同上 API → order_actor POST /close → IBKR
数据链路
实时 K 线IBKR → strategy → Redis PUBLISH → server.js WebSocket → 浏览器
指标排行浏览器每 30s → GET /api/indicators → Redis
订单 / 仓位AutoPM / order_actor → Redis order:update / position:update → WebSocket → 语音 / Toast
账户IBKR reqAccountSummary → Redis account:funds（FA Group 子账户约 3 分钟刷新）
审计Redis 事件 → .run/journal.jsonl → 审计页

图表时间轴使用 ET fake-UTC（与 Redis bar 的 time 字段一致）。RTH 展示 09:30–16:00 ET。

Alpha 审批与执行

超级信号（st_super）

  1. 引擎检测 M1 触线 → 写入 proposal:pending:*
  2. 四宫格 / 历史页 / 飞书卡片 批准实盘（approved_live）
  3. 前端自动开启该标的 auto_strategy=live（Agent 执行）
  4. 超级信号审批后即为 ready_to_execute，下一根 M1 由 AutoRunner 报单
  5. 成交后 AutoPM 挂 OCA 止损 + 半仓止盈；提案状态 → executed

条件 reclaim（非 super）

审批后为 approved_wait，reclaim_watcher 在 M1 收回触发线后设为 ready_to_execute，再执行。

Cursor / MCP

聊天输入 alpha 或「扫信号」→ MCP run_alpha_scan。详见仓库 docs/MCP_ALPHA.md。

启动顺序

1. 基础设施

TWS / IB Gateway 开启 API
redis-server          # 或 brew services start redis
cp env.example .env   # 配置 TRADING_ENV、IB 端口、FA Group 等

2. 引擎 + 前端

python main.py                 # 交易引擎（:8888 网关随引擎启动）
node frontend/server.js      # Web UI :3000

# 或一键
bash scripts/start-stack.sh

3. 常用 URL

四宫格 + 审批/multi.html
单图/ 或 /?symbol=QQQ
配置（只读）/settings.html
收盘审计/audit.html

状态栏 引擎 绿点 = Redis 心跳正常；离线时图表仍可读 Redis 历史，但审批执行 / 平仓需先启动引擎。

文档本页

顶栏 ⏻ 全平：所有持仓反向平仓并激活当日熔断（risk:halt），慎用。

生产护栏
TRADING_ENVpaper 禁止批准实盘、AutoRunner 不报 IBKR；live 才允许真实报单
ORDER_GATEWAY_SECRETlive 模式下 HTTP 8888 / 前端敏感 API 需 Token
AUTO_FIXED_QTY>0 时跳过以损定量；实盘前建议设为 0
日熔断日亏超 1% 自动全平 + 当日禁止开仓
尾盘15:45 ET auto 标的由 AutoRunner EOD；手动 trail 由 ExitManager

修改 .env 后必须重启 main.py。Web 配置页只读，不支持热改。
